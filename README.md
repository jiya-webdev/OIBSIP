# OIBSIP - ATM Interface

## 📌 Project Overview

This project is a console-based ATM Interface developed using Java as part of the OIBSIP Java Development Internship.

The application simulates basic ATM operations through a simple menu-driven interface.

## 🚀 Features

- 🔐 PIN Login
- 💰 Check Balance
- 💸 Withdraw Cash
- 💵 Deposit Cash
- 🔑 Change PIN
- 📋 View Transaction History
- 🔄 Transfer Money
- 🚪 Exit

## 🛠️ Technologies Used

- Java
- Java Collections
- Scanner Class
- Object-Oriented Programming Concepts

## ⚙️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code or any Java-supported IDE.
3. Make sure Java JDK is installed.
4. Open the terminal.
5. Compile the program:
```bash
javac JiyaChaudhary_Task3.java

6.Run the program:
