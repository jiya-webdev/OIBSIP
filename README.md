# OIBSIP - ATM Interface Task 3

## 📌 Project Overview

This project is a console-based ATM Interface developed using Java as part of the OIBSIP Java Development Internship.

The application simulates basic ATM operations through a simple menu-driven interface.

## 🚀 Features

- 🔐 PIN Login
- 💰 Check Balance
- 💸 Withdraw Cash
- 💵 Deposit Cash
- 🔑 Change PIN
- 📋 View Transaction History
- 🔄 Transfer Money
- 🚪 Exit

## 🛠️ Technologies Used

- Java
- Java Collections
- Scanner Class
- Object-Oriented Programming Concepts

## 🎯 Task 2 - Number Guessing Game
### 📌 Project Overview
This project is a console-based Number Guessing Game developed using Java as part of the OIBSIP Java Development Internship.
The computer generates a random number between 1 and 100, and the user has to guess the number within a limited number of attempts.

### 🚀 Features

- 🎲 Random number generation
- 🔢 User guess input
- ⬆️ Too High hint
- ⬇️ Too Low hint
- ✅ Correct guess message
- 📊 Attempts count
- 🔄 Play Again option
- ❌ Game Over message with the correct number

### 🛠️ Technologies Used

- Java
- Random
- Scanner
